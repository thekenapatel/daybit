# 📊 Daybit – Daily Spending Heatmap
Track your spending, one day at a time — visualized beautifully.

### Features
- 🔥 Heatmap view of daily expenses
- 💾 Data stored securely with Firebase
- 🔐 Google & Email authentication
- 🎨 Visual indicators for low to high spend days
- 📅 Clean, calendar-like interface
